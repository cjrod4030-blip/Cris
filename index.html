How to set up Firebase (5 minutes, one time)
  1. Go to console.firebase.google.com and create a free project.
  2. In the project, click the </> Web icon to "Add an app". Name it anything, skip Hosting, and copy the firebaseConfig object it shows you.
  3. Paste that object into the Firebase config box above.
  4. In the Firebase console: Build → Authentication → Get started → Email/Password → Enable → Save.
  5. In the console: Build → Firestore Database → Create database → Start in production mode. Then go to the Rules tab and paste: 
    rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
    }
  }
}
    and click Publish.
  6. Back here, enter an email + password and click Create account. On your other device, paste the same config and click Sign in with the same email/password. Done — your hours will sync.
